# Contributing to FlowLang

Thank you for considering contributing to FlowLang! We appreciate your help in making this project better.

## Code of Conduct
We expect all contributors to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). Please read it before participating in the project.

## Development Setup
1. **Clone the Repository**:  
   Run `git clone https://github.com/Owenjz20/FlowLang.git` to clone the repository.

2. **Install Dependencies**:  
   Navigate into the directory and install the required dependencies. You might use a package manager like npm, pip, or others depending on the setup.

3. **Run the Project**:  
   Follow the instructions in the README to start the project in your local development environment.

## Submitting Contributions
1. **Fork the Repository**:  
   Click on the Fork button at the top right of this page.

2. **Create a New Branch**:  
   Use `git checkout -b your-feature-branch` to create a new branch for your feature or bug fix.

3. **Make Your Changes**:  
   Implement your changes and write clear and concise commit messages.

4. **Push Your Changes**:  
   Use `git push origin your-feature-branch` to push your changes.

5. **Open a Pull Request**:  
   Go to the Pull Requests tab on this repository and click on "New Pull Request." Follow the prompts to create a new pull request.

Thank you for your contributions!
