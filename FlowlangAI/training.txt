============================================================
2. FLOWLANG OVERVIEW
============================================================

FlowLang is a high-level, indentation-based language designed for scripts, apps, and games.

Top-level constructs:
- script:
- app "<name>":
- game "<name>":

You may use one or more of these in a single file, but usually one main entry.

2.1. script:

- Used for simple scripts, utilities, and console-like programs.
- Example:

script:
    set x = 0
    while x < 5:
        print x
        set x = x + 1

2.2. app "<name>":

- Used for GUI applications.
- Contains windows, buttons, labels, inputs, etc.
- Example:

app "demo":
    window "main":
        size 400 300
        title "Demo App"
        label "lblTitle":
            text "Hello from FlowLang"
        button "btnClick":
            text "Click me"
            on click:
                print "Button clicked"

2.3. game "<name>":

- Used for games.
- Contains scenes, entities, input handling, and game loops.
- Example:

game "shooter":
    scene "main":
        player "hero":
            position 0 0
            speed 5
        enemy "e1":
            position 10 0

        on update:
            if key "left" is down:
                move hero -1 0
            if key "right" is down:
                move hero 1 0

============================================================
3. BASIC SYNTAX
============================================================

3.1. Indentation

- Blocks are defined by indentation (like Python).
- 4 spaces per level.
- A colon (:) at the end of a line indicates a block follows.

Example:

script:
    set x = 10
    if x > 5:
        print "big"
    else:
        print "small"

3.2. Variables

- Use `set` to assign:

set name = "FlowLang"
set count = 0
set pi = 3.14

- Variables are dynamically typed.
- You can reassign with `set` again.

3.3. Printing

- Use `print` followed by an expression:

print "Hello"
print x
print "Count: " + count

3.4. Input (optional feature)

- If needed, you can define an input syntax like:

input "Enter your name: " into userName
print "Hello, " + userName

3.5. Expressions

- Support basic arithmetic: +, -, *, /
- Support comparisons: <, >, <=, >=, ==, !=
- Support string concatenation with `+` when one side is a string.
- Example:

set total = price * quantity
if total > 100:
    print "Expensive"

============================================================
4. CONTROL FLOW
============================================================

4.1. if / else

if <condition>:
    <block>
else:
    <block>

Example:

if score >= 100:
    print "You win!"
else:
    print "Try again"

4.2. while

while <condition>:
    <block>

Example:

set i = 0
while i < 10:
    print i
    set i = i + 1

4.3. Functions

func <name>(<params>):
    <block>

- Use `return` to return a value.
- Example:

func add(a, b):
    set result = a + b
    return result

script:
    set x = add(2, 3)
    print x

        button "<buttonId>":

            on click:

5.2. Example: simple click counter

User description:

        title "Counter App"

6. GAME PATTERNS
============================================================

When the user describes a game, use `game "<name>":` with scenes and entities.

6.1. Basic game structure

game "<gameName>":
    scene "<sceneName>":
        player "<playerId>":
            position <x> <y>
            speed <value>

        enemy "<enemyId>":
            position <x> <y>

        on update:
            <logic>

6.2. Movement and input

- Use `on update:` for per-frame logic.
- Use `key "<keyName>" is down` for input.
- Use `move <entity> <dx> <dy>` for movement.

Example:

game "runner":
    scene "main":
        player "hero":
            position 0 0
            speed 5

        on update:
            if key "left" is down:
                move hero -1 0
            if key "right" is down:
                move hero 1 0
            if key "up" is down:
                move hero 0 -1
            if key "down" is down:
                move hero 0 1
